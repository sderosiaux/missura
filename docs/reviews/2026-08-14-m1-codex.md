# Codex review — M1 (2026-08-14)

Independent review (Codex, given docs/SPEC.md + M1-only scope). Verdict: **partial** — the HTTP data plane honors deny-by-default and credential injection; two local-boundary gaps remain, both known M1 shortcuts, now tracked.

| Sev | Finding | Disposition |
|---|---|---|
| High | `missura token` = émetteur local non authentifié, `--ttl` sans borne → un agent avec shell mint un token scope-all quasi éternel | **M2**: `/v1/token` authentifié par clé opérateur remplace le mint libre; TTL hard cap 60 min (SPEC §4.2) partout. NOTE: sur une même machine mono-utilisateur, un agent avec shell reste une limite de classe §28 (documentée) — la vraie étanchéité = `missura exec` sans shell vers `~/.missura`, ou process/container séparé. |
| High | Clé du vault stockée à côté du vault (même `MISSURA_HOME`) → lecture filesystem même-utilisateur = credentials en clair | Connu, assumé v0 (niveau `~/.aws/credentials`). **M4**: keychain OS. Documenté dans SPEC §4.3. |
| Med | Réponses upstream bufferisées sans cap de taille (`arrayBuffer()`) — SPEC dit JSON ≤ 10 MB | **M2**: cap 10 MB sur la réponse (content-length + stream guard), 502 au-delà. |
| Low | `init` interactif affiche les credentials à l'écran (echo) | **M2**: input masqué. |

Le pipeline HTTP lui-même : aucun finding critique, pas de fuite de credential trouvée, pas de bypass catalogue trouvé (après les fixes de la review interne : gate transport Linear, origin enforcement, claims `connections`/`allow`).
