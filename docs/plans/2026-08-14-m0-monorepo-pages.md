# M0 — Monorepo + GitHub Pages + first core brick

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the repo into a pnpm monorepo (site + product packages), deploy the site statically on GitHub Pages, and land the first TDD brick of `@missura/core` (mission token sign/verify) — with an executable proof at the end.

**Architecture:** `apps/site` = the existing Next.js landing, switched to `output: 'export'` (static; the `/api/waitlist` route is replaced by a client POST to a configurable endpoint). `packages/core` = pure TypeScript, no I/O, tested with vitest. Two GitHub workflows: `ci.yml` (lint+test+build on every push) and `pages.yml` (build + deploy static site).

**Tech Stack:** pnpm workspaces, Next.js 16 static export, vitest, node:crypto (HMAC-SHA256), GitHub Actions + actions/deploy-pages.

**Preconditions / decisions locked:**
- GitHub Pages on a PRIVATE repo requires GitHub Pro. If unavailable, everything still works — the `pages.yml` run will fail at deploy until the repo goes public. Acceptable.
- Waitlist endpoint: form POSTs JSON `{email, company}` to `NEXT_PUBLIC_WAITLIST_ENDPOINT` (a webhook/provider URL). If the env var is absent at build time, the form renders a disabled state with a mono note "waitlist opens soon". No fake success, ever.
- Until missura.dev is bought, the site deploys under `https://sderosiaux.github.io/missura` → `basePath` comes from `NEXT_PUBLIC_BASE_PATH=/missura` set in `pages.yml` only. Local dev keeps no basePath.

```bash
gh run watch                            # pages.yml deploys
open https://sderosiaux.github.io/missura   # the landing, live from this repo

```

- [ ] **Step 4: Implement `packages/core/src/token.ts`**

```ts
import { createHmac, randomUUID, timingSafeEqual } from "node:crypto";

export type MissionScope = { customer?: string; repos?: string[] };

export type MissionInput = {
  id: string;
  purpose: string;
  scope: MissionScope;
  connections: string[];
  allow: readonly string[];
};

export type MissionClaims = MissionInput & {
  jti: string;
  iat: number;
  exp: number;
};

const PREFIX = "msr_";

function b64url(buf: Buffer): string {
  return buf.toString("base64url");
}

function hmac(key: Buffer, payload: string): Buffer {
  return createHmac("sha256", key).update(payload).digest();
}

export function signMissionToken(
  mission: MissionInput,
  opts: { key: Buffer; ttlSeconds: number; now?: number },
): string {
  const iat = Math.floor((opts.now ?? Date.now()) / 1000);
  const claims: MissionClaims = {
    ...mission,
    jti: randomUUID(),
    iat,
    exp: iat + opts.ttlSeconds,
  };
  const payload = b64url(Buffer.from(JSON.stringify(claims), "utf8"));
  const sig = b64url(hmac(opts.key, payload));
  return `${PREFIX}${payload}.${sig}`;
}

export function verifyMissionToken(
  token: string,
  opts: { key: Buffer; now?: number },
): MissionClaims {
  if (!token.startsWith(PREFIX)) throw new Error("invalid token format");
  const body = token.slice(PREFIX.length);
  const dot = body.lastIndexOf(".");
  if (dot < 0) throw new Error("invalid token format");
  const payload = body.slice(0, dot);
  const sig = Buffer.from(body.slice(dot + 1), "base64url");
  const expected = hmac(opts.key, payload);
  if (sig.length !== expected.length || !timingSafeEqual(sig, expected)) {
    throw new Error("invalid signature");
  }
  const claims = JSON.parse(
    Buffer.from(payload, "base64url").toString("utf8"),
  ) as MissionClaims;
  const now = Math.floor((opts.now ?? Date.now()) / 1000);
  if (claims.exp <= now) throw new Error("token expired");
  return claims;
}
```
